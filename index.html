Design surface (finished grade)

The engineer's finished-grade surface is loaded. With the GPS rover, the target grade is taken from the surface right where you stand – no target points needed. Tapping the plan for a laser shot fills in the finished grade too.
Target is finished grade (top of pavement, curb, slab). For dirt, set a depth with Set target → offset chips → Use design surface (e.g. −8" for the pavement section).

GPS elevation (RTK rover)

With an RTK rover feeding the tablet, Site Grade reads elevation as you walk – no laser or rod reading. Calibrate once on a known elevation (the slab), then the Plan tab shows live CUT/FILL.
Keep the pole the same height after calibrating (and the same Instrument Height in GNSS Master) – the calibration cancels the pole height and the GPS height datum. Re-calibrate if you change either.

GPS on the plan

Lines the plan up with the phone's GPS using control points (purple crosshairs). Defaults are the 4 building corners – move, rename, add or delete them on the Plan tab in 📍 Cal mode. Stand on each one and tap Capture GPS here.
Uses the plan's 1"=30' scale so only position and rotation come from GPS. Turn off only if the plan image isn't to scale.

Settings
